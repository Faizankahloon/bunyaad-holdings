# Bunyaad Holdings website starter

## Run locally
1. Install Node.js 20+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. Run `npm run build` to create the production build.

## Included
- Responsive React/Vite single-page site with Home, About, Projects, four project detail routes, Our Developments, and Contact.
- Navy / gold / ivory visual system and Manrope + Inter typography.
- Mobile navigation, project carousel, WhatsApp and click-to-call links.
- Project-prefilled enquiry forms and basic client-side validation.
